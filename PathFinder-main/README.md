# Path Finding Visualizer

An interactive web application for visualizing pathfinding and maze generation algorithms. The project helps users understand how different algorithms explore a grid and find paths through animated step-by-step execution.

## Features

- Interactive grid visualization
- Generate random mazes
- Visualize multiple pathfinding algorithms
- Adjustable animation speed
- Clear and reset the grid
- Responsive user interface

## Algorithms Implemented

### Pathfinding
- Breadth-First Search (BFS)
- Depth-First Search (DFS)
- Greedy Best-First Search
- A* Search

### Maze Generation
- Randomized Depth-First Search
- Prim's Algorithm
- Kruskal's Algorithm
